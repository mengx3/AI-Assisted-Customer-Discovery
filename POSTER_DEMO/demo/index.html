How It Works
End-to-End Pipeline
One command takes raw customer data through cleaning, feature engineering, unsupervised segmentation, and supervised conversion prediction.
$ python scripts/generate_sample_data.py --out data/raw/customers.csv --n 2000
Wrote sample data: data/raw/customers.csv (2000 rows)

$ python scripts/run_pipeline.py --input data/raw/customers.csv --outdir outputs
✅ Pipeline complete.
- Cleaned data: outputs/data/customers_cleaned.csv
- Cluster profiles: outputs/reports/cluster_profiles.csv
- Model: outputs/models/conversion_model.joblib
- Metrics: outputs/reports/metrics.json
📥
STEP 01

Data Ingestion

Read CSV or Excel files with automatic format detection and schema validation.

🧹
STEP 02

Cleaning

Normalize columns, deduplicate, handle missing values, and generate a cleaning report.

📊
STEP 03

EDA & Features

Auto-detect column types, one-hot encode, standardize, and impute.

🎯
STEP 04

Segmentation

K-Means with silhouette-based K selection. Automatically profiles each cluster.

🤖
STEP 05

Prediction

Train Random Forest or Logistic Regression to predict conversion.

💾
STEP 06

Artifacts

Save cleaned data, model, preprocessor, metrics, and cluster profiles.
